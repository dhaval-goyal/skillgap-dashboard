# SkillGap AI

A Streamlit prototype for manually assessing selected skills,
calculating weighted proficiency scores, and identifying learning gaps.

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the dashboard:

    streamlit run app.py

## Important limitations

Scores are manually entered. This prototype does not automatically
grade assessments, verify projects, or establish job readiness.
The current deployment does not load the project's saved ML models.
